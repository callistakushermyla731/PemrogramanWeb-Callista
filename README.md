LATIHAN REFLEKTIF
1. Atribut required digunakan untuk data primer/utama: "Nama" dan "No. Anggota" adalah identitas dasar yang wajib ada untuk membedakan antar-anggota agar tidak terjadi data ganda atau anonim.
   Alamat dan No. HP bersifat opsional: Tidak semua sistem mewajibkan pengisian data kontak sejak awal, atau ada kondisi di mana calon anggota belum memiliki No. HP/alamat tetap. Tanpa required, formulir tetap bisa dikirim meskipun kedua kolom tersebut dikosongkan.
2. Browser akan menghentikan proses pengiriman form (submit) secara otomatis. Browser memunculkan peringatan visual bawaan HTML5 (pop-up/tooltip) tepat di atas atau di bawah kolom "Nama" dengan pesan seperti "Please fill out this field" (atau "Harap isi bidang ini"). Kursor/fokus (focus) akan langsung berpindah ke kolom "Nama" tersebut agar pengguna segera mengisinya.
3. Ketika action kosong (atau berisi action="#"), browser akan mengarahkan dan memproses data form ke halaman yang sedang dibuka saat itu juga (current URL). Tampilan halaman akan mengalami muat ulang (reload), dan data yang diisikan di formulir akan ditambahkan ke bagian belakang URL (jika menggunakan method GET) atau sekadar menyegarkan halaman tanpa berpindah ke file pemrosesan backend seperti PHP.
